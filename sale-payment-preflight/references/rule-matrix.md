# 买卖合同货款追索诉前审查规则矩阵

> 状态：律师审定前版本。仅用于境内 B2B 货物买卖、卖方主张未付货款的案卷预整理，不构成法律意见。

## 使用原则

1. 先审范围，再审事实；超出 Skill 范围时只做材料清单并转人工。
2. 将“发现材料线索”与“法律上足以证明”分开。脚本只能给出前者。
3. 每一事实、矛盾和补证建议均保留材料编号及页码、工作表、行号或段落位置。
4. 无书面合同时综合审查交易方式、交易习惯、订单、交付、结算、发票和往来信息，不以单一材料自动认定合同成立。
5. 发票、送货、签收、验收、对账、付款分别审查，禁止相互替代。
6. 时效、管辖、仲裁、利息、违约金及胜诉可能性必须由律师独立判断。

## 律师复核顺序

### 1. 主体及授权

- 核对委托方、相对方、签约方、开票方、收付款方是否一致。
- 核对签约、收货、对账和承诺付款人员的身份及权限。
- 对第三方付款、关联公司履行、债权转让或债务加入单列事实，不自动归因。

### 2. 合同基础

- 有书面合同时核对合同及附件、订单、报价、签章页和变更文件。
- 无书面合同时列出形成交易关系的全部材料链，并明确反证和待核实交易习惯。
- 对标的、数量、单价、总价、付款期限、检验、争议解决及违约条款分别定位。

### 3. 履约及验收

- 按订单或批次匹配出库、物流、送货、收货和验收材料。
- 标记签收人不明、数量不一致、缺页、复印件、无法验证电子数据等缺陷。
- 单列质量异议、退换货、折让、维修和质保事实；存在复杂反诉迹象时退出自动审查。

### 4. 结算及付款

- 对账单或债权确认须核验主体、签章、权限、期间和是否变更原约定。
- 货款表只计入 `确认状态=已确认` 且币种为 CNY 的应收、付款、退货和折让。
- 未付本金计算公式：`应收 - 付款 - 退货 - 折让`。不得在 v1 中计算利息、违约金、诉讼费或保全费。

### 5. 程序和证据形式

- 抽取但不裁判管辖或仲裁条款；检查候选法院、实际联系和专属/级别管辖问题。
- 罗列付款期限、催告、对账、还款承诺等候选时效事实，不给出最终时效结论。
- 登记证据名称、编号、来源、证明对象、原件状态、页数和提交日期；电子数据关注完整性和原始载体。

## 结果用语

- 使用：`已发现材料线索`、`待补充/待核实`、`超出范围`、`律师复核后确定`。
- 禁止：`必然成立`、`必然败诉`、`胜诉率`、`法院一定支持`、`已过诉讼时效`。
