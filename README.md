# LayerSkills

这是一个面向法律 AI Skill 的本地项目仓库，重点聚焦在卖方 B2B 货款回收前置审查流程。

## 项目内容

- `sale-payment-preflight/`：核心 Skill 目录，包含规则、脚本、参考资料和测试用例。
- `outputs/`：运行输出目录，默认忽略不提交。
- `tmp/`：临时构建和调试产物，默认忽略不提交。
- `submission/`：投稿、盲测和交付材料目录。

## 主要能力

该 Skill 适用于：

- 对卖方、国内 B2B 货款收款案件进行离线预检
- 建立案件材料清单与履约事实时间轴
- 识别要件、证据差异和缺失问题
- 生成律师复核前的工作底稿和输出文档
- 把法务审查逻辑与证据链保持在可追溯、可审计范围内

## 使用说明

1. 进入 `sale-payment-preflight/` 目录查看 Skill 定义与脚本。
2. 按照 `SKILL.md` 中的流程执行案例预检。
3. 使用本地配置文件和案例目录运行脚本。
4. 将输出结果保存在 `outputs/` 或单独目录中，不建议提交到 Git。

## 版本管理

- 代码与脚本保留在仓库中。
- 生成产物、缓存、临时目录和大文件已在 [.gitignore](.gitignore) 中排除。

## 维护建议

- 保留源文件、规则和可复现脚本。
- 避免将运行结果、缓存、PDF/XLSX/Word 中间产物提交到仓库。
- 适合将可复现成果和说明材料与 GitHub 代码仓库一起管理。
